## Pre-launch checklist

Every `manual` item, in the order to do them. Each links to the runbook with the steps.

### Accounts and hosting

- [ ] Hosting accounts and the one-time setup in [deployment.md](runbooks/deployment.md): GitHub
      branch protection, `staging` and `production` environments (production with required
      reviewers), Render Blueprint (`render.yaml`), Vercel project, every secret in the secret
      managers (NFR-S13).
- [ ] MongoDB Atlas production cluster: Continuous Cloud Backup on, 35-day retention, region
      recorded (NFR-B1, NFR-B3, FR-D4, NFR-PR5) ([database-restore.md](runbooks/database-restore.md)).
- [ ] Resend: domain verified with SPF, DKIM and DMARC; staging and production sending keys
      (FR-A2, SRS 2.3) ([deployment.md](runbooks/deployment.md) → Email).
- [ ] Sentry: two projects, DSNs and source-map tokens, scrubbing options on; one test error per
      environment shows TypeScript stack traces (NFR-O2) ([observability.md](runbooks/observability.md)).
- [ ] Render cron services created and run once (FR-A12) ([scheduled-jobs.md](runbooks/scheduled-jobs.md)).

### Operations

- [ ] Log drain with 30-day retention (NFR-B5), dashboards and alerts (NFR-O3), uptime monitors
      and status page (NFR-A1), on-call rota and paging (NFR-O4)
      ([observability.md](runbooks/observability.md), [incident-response.md](runbooks/incident-response.md)).
- [ ] First release through the pipeline: staging smoke test, production approval, 30-minute
      watch ([deployment.md](runbooks/deployment.md)). Then create the first admin
      ([admin-bootstrap.md](runbooks/admin-bootstrap.md)).
- [ ] First restore drill, timed against the 4-hour RTO; add the row to the drill log
      (NFR-B2, NFR-B4, AC-22) ([database-restore.md](runbooks/database-restore.md)).
- [ ] Dependabot and the monthly update routine owner named (NFR-M7)
      ([dependency-updates.md](runbooks/dependency-updates.md)).

### Verification on staging

- [ ] k6 load test at 200 users: NFR-P5 and AC-19 / NFR-P2 thresholds pass (NFR-P6)
      ([load-testing.md](runbooks/load-testing.md)).

      users and 500,000 links (NFR-P4) ([load-testing.md](runbooks/load-testing.md)).
- [ ] Browser matrix, latest two versions each of Chrome, Edge, Firefox and Safari: sign up,
      verify, save, pin, copy, QR, search, admin (NFR-U4).

      ([penetration-test.md](runbooks/penetration-test.md)).
